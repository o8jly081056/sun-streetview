    輸入 Google Maps API 金鑰

    金鑰只存在你這台電腦的瀏覽器（localStorage），不會上傳到其他地方。

    1. 到 Google Cloud Console 建立專案並綁定帳單（個人用量通常在每月免費額度內）
    2. 啟用 Maps JavaScript API（必要）、Places API (New)（搜尋與匯入收藏）、Geocoding API（選用，地址反查）
    3. 建立 API 金鑰，建議在「應用程式限制」設定 HTTP 參照網址為 http://localhost:8765/*

    儲存到清單

    匯入 Google 地圖收藏

    Google 沒有開放 API 讀取個人收藏，需要先用 Google Takeout 匯出一次再匯入：

    1. 打開 Google Takeout，先按「取消全選」
    2. 勾選 「已儲存」（收藏清單，每個清單一個 CSV）與 「地圖 (你的地點)」（加星號地點 JSON）
    3. 匯出並下載 zip，解壓縮後把裡面的 .csv / .json 拖進下方

    也支援「我的地圖」匯出的 .kml、一般 .geojson，以及本工具的備份檔。CSV 若沒有座標，會用地點名稱透過 Places API 自動查找。

    把檔案拖到這裡，或點此選擇檔案（可多選）
